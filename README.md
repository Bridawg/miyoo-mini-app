# miyoo-mini-app

Onion OS app to connect to a RomM server and fetch games

## Development

Significant portions of the `work/bug-fixes` branch were developed with
AI assistance ([Claude Code](https://claude.ai/code), Anthropic). This
includes the cross-compilation build system, themed SDL UI, cover art
pipeline, settings screen, and virtual keyboard. All AI-assisted commits
reference the originating session in their commit message.

```sh
sudo apt-get install libjson-c-dev libsdl2-dev libsdl2-ttf-dev
```

```sh
brew install cmake json-c sld2 sdl2_ttf sdl12-compat sdl_ttf --force
```
